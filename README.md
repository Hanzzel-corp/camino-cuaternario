# Camino Cuaternario

Iniciativa independiente de recaudación de fondos de Hanzzel Corp.

## Página pública

https://hanzzel-corp.github.io/camino-cuaternario/

## Objetivo publicado

La página establece una meta de recaudación de **500.000 USD** y presenta un indicador de progreso que obtiene el valor actual desde `data.json`.

## Archivos del repositorio

- `index.html`: página pública, presentación de la iniciativa y visualización del progreso.
- `data.json`: dato de progreso consumido por la página.

## Funcionamiento documentado

La página consulta `data.json`, valida el valor numérico `current`, lo compara con la meta publicada y actualiza la barra de progreso. Si el archivo no está disponible o el dato no es válido, muestra un mensaje de indisponibilidad.

La página menciona Patreon como canal de donación previsto, pero también indica que el enlace oficial de la página de creador no pudo recuperarse. Por lo tanto, este README no publica ni inventa un enlace de donación.

## Alcance

Camino Cuaternario se documenta como una iniciativa de recaudación. No se clasifica aquí como investigación científica, software comercial ni producto NCT.
